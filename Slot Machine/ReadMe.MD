# Project Description

The **Happy Friends Slot Machine** is a browser-based slot machine game developed using **HTML, CSS, and JavaScript**. Instead of traditional casino symbols, the game uses photos of friends as slot symbols, making the game more personal and entertaining.

Players begin with a starting balance, place bets, spin the reels, and earn payouts by matching symbols. The game also includes an automatic spin mode, animated reels, a payout table, and a customized background featuring memorable photos.

# Project Title and Chosen Theme

**Project Title:** Happy Friends Slot Machine
**Chosen Theme:** Happy Friends

The project celebrates friendship by replacing traditional slot machine icons with photos of friends and memorable moments. The background collage and slot symbols are all based on the Happy Friends theme, giving the game a personalized and fun appearance.

# How to Run the Project

1. Download or clone the project folder.
2. Make sure the folder structure remains unchanged.
3. Verify that all image files are inside the `images/` folder.
4. Open the project folder.
5. Double-click `index.html`, or open it in any modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
6. The game will load automatically and is ready to play.

# How to Play

1. Start with the initial balance.
2. Increase or decrease your bet using the **+ Bet** and **− Bet** buttons.
3. Click **Spin** to play one round.
4. Match symbols on any horizontal row to earn payouts.
5. Enable **Auto Spin** for continuous gameplay until you stop it or your balance becomes insufficient.
